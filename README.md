# MoneyTrack

Plataforma de finanzas personales con IA para Costa Rica y América Latina: todo tu dinero (bancos, SINPE Móvil, tarjetas, efectivo, cripto e inversiones) en un solo lugar, en colones y dólares, sin depender del open banking.
